# ValiDate Tester

![tag:innovationlab](https://img.shields.io/badge/innovationlab-3D8BD3)
![tag:hackathon](https://img.shields.io/badge/hackathon-5F43F1)

A test client for the ValiDate team. It plays a founder: for each test interview it tells the ValiDate agent the idea, sends the transcript, and records the verdict. It also asks the ValiDate Signal Analyst for its sentence labels, and compares both with an answer key to measure accuracy.

It only sends messages; it does not answer requests from other agents.
